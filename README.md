# Helen Akopova Makeup Academy — Hero Section

Премиальный первый экран официального сайта **Helen Akopova Makeup Academy** в эстетике Minimalist Luxury & Editorial Beauty.

## Особенности реализации
- **Header:** Оригинальный логотип, капсульная навигация («Главная», «Услуги», «Работы», «Отзывы», «Контакты») и аккуратная кнопка записи.
- **Hero Section:** Сбалансированный заголовок «Макияж — это искусство» на шрифте Bodoni Moda, подзаголовок, группа действий («Записаться» и «Смотреть работы →»).
- **Студийный визуал:** Оригинальная фотография команды визажистов и моделей на бесшовном студийном молочном фоне (`#F3EBE7`), без обрезания моделей.
- **Интерактивность:**
  - Экспресс-лукбук работ академии при клике на «Смотреть работы» или пункт «Работы».
  - Модальное окно записи на обучение с выбором программы.
  - Уведомление «Раздел в разработке» при переходе по разделам в процессе наполнения.
  - Полная адаптивность под десктоп, планшет и мобильные устройства.

## Структура файлов
- `index.html` — семантическая разметка (Header и Hero Section)
- `style.css` — стили, адаптивные медиа-запросы, типографика и модальные окна
- `script.js` — интерактивная логика модальных окон, навигации и лукбука
- `assets/` — графические ресурсы (логотипы, фотографии)
- `mockups/` — рендеры экранов в высоком разрешении
